// ENVIRONMENT SETUP
01

Download MongoDB MSI Installer

Get the official Community Server installer for Windows.

1 Go to mongodb.com/try/download/community
2 Select Windows platform, MSI package, latest version
3 Click Download — file will be named mongodb-windows-x86_64-X.X.X.msi
TIP Also check "Install MongoDB Compass" during setup — it comes bundled with the MSI installer.
02

Run the MSI Installer

Install MongoDB as a Windows Service so it runs automatically.

1 Double-click the downloaded .msi file and click Next
2 Accept the license agreement, choose Complete setup type
3 On the Service Configuration screen, leave defaults — Install MongoD as a Service should be checked
4 Ensure Install MongoDB Compass is checked, then click Install
03

Verify Installation in Terminal

Confirm MongoDB shell is accessible from your command line.

Open Command Prompt or PowerShell and run:

TERMINAL 
mongosh --version
Expected Output
C:\Users\you> mongosh --version
2.x.x
NOTE If the command is not recognized, add MongoDB's bin folder to your system PATH:
C:\Program Files\MongoDB\Server\X.X\bin
// COMPASS CONNECTION
04

Connect via MongoDB Compass

Use the GUI to establish a local connection on port 27017.

1 Launch MongoDB Compass from the Start Menu
2 In the connection string field, enter the URI below and click Connect
CONNECTION URI 
mongodb://localhost:27017

05

Create Database & Collection

Set up unify_labs database with an interns collection.

1 In Compass, click + Create database in the left sidebar
2 Set Database Name to unify_labs
3 Set Collection Name to interns
4 Click Create Database
