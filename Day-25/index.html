01

Increase Electronics Price

Use $inc to raise all Electronics prices by +10.

$inc adds to the existing value. Positive = increase, negative = decrease.
MONGOSH
db.products.updateMany(
  { category: "Electronics" },
  { $inc: { price: 10 } }
)

Flag Featured Products

Set featured: true for all items where price > 500.

$gt means "greater than". After step 1, the 4K Monitor is now $509.99 — it qualifies.

db.products.updateMany(

03

Update Category Name

Rename "Clothing" to "Apparel" across all documents.

MONGOSH
db.products.updateMany(
  { category: "Clothing" },
  { $set: { category: "Apparel" } }
)
Verify rename
db.products.find({ category: "Apparel" })
// returns Denim Jacket + Linen Shirt
04

Push Tag to New Arrivals

Add "new-arrival" tag to items with stock > 100.

$push appends a value to an array field. If the field doesn't exist, MongoDB creates it automatically.
MONGOSH
db.products.updateMany(
  { stock: { $gt: 100 } },
  { $push: { tags: "new-arrival" } }
)
Expected doc shape
{
  name: 'Linen Shirt',
  stock: 200,
  tags: [ 'new-arrival' ]
}
// CLEANUP
05

Delete Zero-Stock Items

Remove all documents where stock equals 0.

⚠ Destructive operation. Always run a find() with the same filter first to preview what will be deleted.
PREVIEW FIRST
db.products.find({ stock: 0 })
THEN DELETE
db.products.deleteMany({ stock: 0 })
