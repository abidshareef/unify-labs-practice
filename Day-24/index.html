Find Electronics

Filter all products where category is "Electronics".

MONGOSH
db.products.find({ category: "Electronics" }).pretty()
Expected Output
// 2 documents returned
{ name: 'Wireless Headphones', category: 'Electronics', price: 149.99, ... }
{ name: '4K Monitor', category: 'Electronics', price: 499.99, ... }
04

Top 2 Most Expensive

Sort by price descending, limit to 2.

MONGOSH
db.products.find().sort({ price: -1 }).limit(2).pretty()
Expected Output
// Sorted desc · limit 2
{ name: '4K Monitor', price: 499.99, category: 'Electronics' }
{ name: 'Oak Desk', price: 349.99, category: 'Furniture' }
-1 = descending  |  1 = ascending  |  .limit(n) caps the result set.
